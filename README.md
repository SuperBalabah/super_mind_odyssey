# 🪐 Super Mind Odyssey (心智拓荒者)

> **每日 3 分鐘，無痛搞懂跨領域核心心智模型。**
> 拒絕教科書枯燥長文，以「情境抉擇先於概念」、「費曼白話防禦」、「虛線名詞即時字典」、「課後三扇門探險」、「迷霧技能星圖」與「GitHub Gist 零成本雲端同步」打造的心智冒險 PWA。

---

## 🌟 核心設計特色

1. **情境抉擇開局 (Dilemma First)**
   - 拒絕直接上課！每次探索以一個 15 秒情境二選一（如：小豬該不該去按按鈕？要不要主動坦白同夥？）開始。
   - 做出決策後即時展示群體數據與反直覺復盤，激發探索本能。

2. **零術語負債 (Zero Jargon Debt)**
   - 嚴格遵守費曼學習法，所有內文以小學生能懂的生活化比喻（如超商、排隊、辦公室）切入。
   - 任何專業名詞（如「佔優策略」、「逆向選擇」）均標註**紫色點狀虛線**，點擊即彈出 20 字內純白話氣泡字典，不打斷閱讀韻律。

3. **課後好奇心三扇門 (Choose Your Own Adventure)**
   - 讀完卡片後，不再被動接收隨機內容，而是由你親手選擇明天的航線：
     - **門 A（深入同域）**：例如從「囚徒困境」深入到「重複博弈與以牙還牙」。
     - **門 B（跨界跳躍）**：例如從「博弈論」跨跳到「經濟學檸檬市場」。
     - **門 C（反常識翻轉）**：例如「智豬博弈中弱者的獲勝反思」。
     - 或是點擊 **🎲 隨機開啟全新迷霧**。

4. **戰爭迷霧星圖 (Fog of War Map) & 思維神器 (Mind Relics)**
   - 初始狀態下，未探索領域籠罩在神秘迷霧中。
   - 點亮節點後驅散相鄰迷霧，收集各領域的神器（如「搭便車指南針」、「無悔沙漏」），並生成專屬的「拓荒決策風格畫像」。

5. **極致離線 PWA ＋ 零成本 GitHub Gist 雙端同步**
   - **完全離線可用**：Service Worker 快取所有資源，手機斷網、飛航模式照樣秒開。
   - **跨端無縫**：手機與電腦進度可透過個人的 GitHub Gist 靜默同步，不花一毛伺服器費用。

6. **原生 Web Audio 音效引擎**
   - 100% 由瀏覽器原生 Web Audio API 合成，零外部音檔依賴，帶來紙牌翻閱、開門傳送與神廟解鎖的極致反饋。

## 🚀 快速啟動

本專案為標準純前端 Web App / PWA，無須任何繁重環境安裝即可直接執行：

### 1. 本地啟動
在專案根目錄下使用任何靜態伺服器：
```bash
# 使用 Python
python -m http.server 8080

# 或使用 Node.js
npx serve .
```
在瀏覽器打開 `http://localhost:8080` 即可體驗！

### 2. 手機 PWA 安裝
- 使用手機 Safari 或 Chrome 打開網址。
- 點擊「分享」或選單 -> **「加入主畫面 (Add to Home Screen)」**。
- 即可像原生 App 一樣全螢幕獨立運行，支援完全離線使用。

## 🤖 全自動內容生成管線 (Zero-Cost Pipeline)

若想自動擴充更多卡片，本專案提供多備援免費 API 生成腳本：

```bash
# 設定免費 API Key (可使用 Google AI Studio 或 OpenRouter :free 模型)
export GEMINI_API_KEY="你的免費API_KEY"

# 執行生成腳本
node scripts/generate_cards.js --domain="行為經濟學"
```

配合 `.github/workflows/daily_mind_cards.yml`，可直接託管在 GitHub 免費自動排程更新！
