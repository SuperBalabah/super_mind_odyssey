## 💡 這是什麼？（核心理念與用途）

我們每天面對無數複雜決策（工作職場、投資理財、人際溝通、軟體架構），卻常受限於單一專業視角的思考盲區。查理·蒙格（Charlie Munger）曾提出：**「要成為一個清醒的思考者，你的大腦必須擁有一個由跨領域核心心智模型組成的格柵網絡。」**

**Super Mind Odyssey** 是一個現代化、零門檻的心智模型拓荒引擎：
- **零壓力日常學習**：每天只花 3 分鐘，不灌輸生硬理論，用「生活化情境」切入。
- **開箱即用，免註冊**：直接開啟網頁即可暢玩，預載 20+ 個橫跨博弈論、經濟學、認知心理學、資訊論、演化生物學的核心模型。
- **永久免費、無伺服器維護負擔**：全前端架構，可透過 GitHub Gist 實現手機與電腦的雙向存檔同步，無須自建資料庫，亦無個資外洩風險。

## ✨ 核心特色與體驗閉環

```
   ┌─────────────────────────────────────────────────────────────┐
   │                  1. 今日拓荒：情境抉擇開局                   │

   └─────────────────────────────────────────────────────────────┘
```

1. **情境抉擇先於概念 (Dilemma First)**
   - 不再從枯燥定義開始！以「智豬博弈小豬該不該去按按鈕？」或「職場分工要不要主動坦白？」等情境切入，先做出直覺判斷，再看大眾統計與反直覺解析。
2. **零術語負債 (Zero Jargon Debt)**
   - 嚴格遵守費曼學習法。內文中出現的所有專有名詞（如「佔優策略」、「逆向選擇」）均帶有**紫色點狀虛線**，點擊即彈出 20 字內純白話氣泡字典，絕不打斷閱讀流。
3. **向未知深處追問 & 筆記沉澱 (AI Deep Inquiry & Personal Notes)**
   - 讀完卡片意猶未盡？可向 AI 提出深度疑問（支援即時聯網模型），並可點擊「保存筆記至心智法典」，將重要思考永久收錄於該知識點中。
4. **自主航線：課後三扇門 (Choose Your Own Adventure)**
   - 告別系統隨機塞題！每次探索完成後，由你親手推開下一扇門：
     - **門 A（同領域深入）**：如從「囚徒困境」進階到「重複博弈與以牙還牙」。
     - **門 B（跨學科跳躍）**：如從「博弈論」橫跨至「經濟學檸檬市場」。
     - **門 C（反常識翻轉）**：逆向思考與反思邊界。
5. **思維陳列室 (Mind Showcase Cabinet)**
   - 採用直覺的分層實木收納櫃設計，將學科（博弈論、經濟學、認知偏差等）做成 3D 收納盒。點擊收納盒展開該學科的所有「已點亮節點」與「迷霧未知節點」，點選節點可直接閱讀心智法典與個人筆記。
6. **思維疆界探索雷達 (Uncharted Topic Radar)**
   - 點擊頂部雷達圖示，可自由發射 AI 探測器合成任何未收錄學科（如「控制論反饋調節」、「夏農資訊熵」、「奧卡姆剃刀」），即時擴充個人知識宇宙。
7. **原生 Web Audio 音響回饋**
   - 100% 透過瀏覽器原生 Web Audio API 即時合成音效，零外載音檔，擁有細膩的翻牌、開門與星際共振體驗。

## 🔑 申請指南：手把手教你取得各項金鑰

### 1. GitHub Personal Access Token (PAT) 申請步驟
> 用於讓網頁具備將存檔寫入自己 GitHub Gist 的權限。

1. 登入 GitHub，前往金鑰管理頁面：  
   👉 **[https://github.com/settings/tokens](https://github.com/settings/tokens)**（或點擊個人頭像 ➔ `Settings` ➔ 左下角 `Developer settings` ➔ `Personal access tokens` ➔ `Tokens (classic)`）。
2. 點擊右上角 **"Generate new token"** ➔ 選擇 **"Generate new token (classic)"**。
3. 填寫設定：
   - **Note**：輸入自訂備忘名稱，例如 `super-mind-odyssey-sync`。
   - **Expiration**：過期時間，建議選擇 `No expiration`（無過期時間）或依個人習慣。
   - **Select scopes（重要權限設定）**：
     - **只需勾選 `gist`（Create gists）** 這一項。
     - ⚠️ **請勿勾選** `repo`、`admin` 或其他無關權限（遵循最小權限原則）。
4. 滾動到頁面最底部，點擊綠色按鈕 **"Generate token"**。
5. 頁面將顯示一串以 `ghp_` 開頭的金鑰字串：
   - 點擊旁邊的複製圖示（注意：該畫面關閉後將無法再次查看，請妥善複製）。
6. 回到 Super Mind Odyssey 點擊右上角 ⚙️，將其貼入 **「GitHub Personal Access Token (PAT)」** 欄位。

---

### 2. GitHub Gist ID 建立與取得步驟
> Gist 是 GitHub 提供的免費輕量代碼與文字剪貼簿，本專案將其作為你的免費個人雲端存檔。

1. 前往 GitHub Gist 建立頁面：  
   👉 **[https://gist.github.com](https://gist.github.com)**
2. 填寫 Gist 內容：
   - **Gist description**：填寫 `Super Mind Odyssey Save Data`（可自訂）。
   - **Filename including extension**：輸入 `mind_odyssey_data.json`。
   - **內容文字框**：輸入 `{}` （一對大括號即可，做為初始空白存檔）。
3. 點擊右下角綠色按鈕旁邊的下拉箭頭，選擇 **"Create secret gist"**（建立私有 Gist，避免他人檢視你的學習進度）。
4. 建立成功後，觀察瀏覽器網址列的 URL，結構如下：
   ```
   https://gist.github.com/<你的GitHub帳號>/<32位的英數字ID>
   ```
   *例如：`https://gist.github.com/octocat/9684affee920c8a1b2c3d4e5f6a7b8c9`*
5. 網址最後面的 **32 位英數字字串** 即為你的 **Gist ID**。
6. 回到 Super Mind Odyssey 點擊右上角 ⚙️，將此 ID 貼入 **「GitHub Gist ID」** 欄位，點擊「儲存設定」即可！
7. **同步測試**：進入「探險日誌」分頁，點擊「📤 手動上傳至雲端」或「📥 從雲端同步下來」即可測試雙向同步。

---

### 3. Google Gemini API Key 免費申請步驟
> 提供頂級的大語言模型能力，讓你在閱讀心智模型時能發起任意深度追問，或自主生成全新學科領域。

1. 前往 Google AI Studio：  
   👉 **[https://aistudio.google.com/app/apikey](https://aistudio.google.com/app/apikey)**
2. 登入你的 Google 帳號。
3. 點擊藍色按鈕 **"Create API key"**（或 "Get API key"）。
4. 選擇你的 Google Cloud 專案（若從未建立過，系統會引導你一鍵建立預設專案）。
5. 建立完成後，複製產生的 API Key 字串（格式通常為 `AIzaSy...` 或類似代碼）。
6. 回到 Super Mind Odyssey 點擊右上角 ⚙️，將其貼入 **「Gemini API Key」** 欄位。
7. *費用說明：Google AI Studio 針對個人開發者提供極為慷慨的 Free Tier 免費配額，日常探索學習完全無須付費。*

---

### 4. OpenRouter API Key 申請步驟（選填備援）
> 當 Gemini 遇到每日免費請求上限時，OpenRouter 可作為全自動切換的備援線路。

1. 前往 OpenRouter 官網：  
   👉 **[https://openrouter.ai/keys](https://openrouter.ai/keys)**
2. 點擊右上角登入（支援 Google 或 GitHub 帳號一鍵登入）。
3. 進入 **API Keys** 頁面，點擊 **"Create Key"**。
4. 輸入金鑰名稱（例如 `mind-odyssey`），點擊確認。
5. 複製產生的金鑰（格式為 `sk-or-v1-...`）。
6. 回到 Super Mind Odyssey 貼入 **「OpenRouter API Key」** 欄位。

## 🛡️ 隱私安全承諾 (Privacy & Security)

本專案高度重視使用者隱私與資訊安全：

1. **純前端無伺服器 (100% Client-Side)**：
   - 本應用無任何專屬後端伺服器，不設有任何能接收使用者資料的資料庫。
2. **本機隔離存儲 (LocalStorage Only)**：
   - 您填寫的 GitHub Token、Gist ID、Gemini Key 等機敏資訊，**僅保存在您本機裝置的瀏覽器 LocalStorage 中**。
3. **直連官方端點**：
   - 雲端同步時，瀏覽器直接與 `https://api.github.com` 通訊。
   - AI 探測追問時，瀏覽器直接與 `https://generativelanguage.googleapis.com` 通訊。
   - 絕不經過任何第三方反向代理或轉發伺服器。
4. **無追蹤代碼**：
   - 無 Google Analytics、無廣告腳本、無第三方 Cookie 追蹤，純淨透明開源。

## 📱 手機 PWA 安裝指南（離線暢玩）

本專案支援標準 Progressive Web App 規格，安裝後可獲得如同原生 App 的流暢體驗：

1. 使用 **Safari** 瀏覽器開啟 [線上體驗網址](https://superbalabah.github.io/super_mind_odyssey/)。
2. 點擊瀏覽器底部的 **「分享」** 按鈕（向上箭頭方形圖示）。

4. 點擊右上角「新增」，手機桌面即會出現「心智拓荒者」專屬圖示。

### Android (安卓手機 / 平板)
1. 使用 **Chrome** 瀏覽器開啟 [線上體驗網址](https://superbalabah.github.io/super_mind_odyssey/)。
2. 點擊右上角選單（三個點點）或底部跳出的橫幅。
3. 選擇 **「安裝應用程式」** 或 **「新增至主螢幕」**。
4. 安裝完成後即可以獨立全螢幕運行，斷網與飛航模式下亦可秒速啟動！

## 💻 本地開發與部署 (Local Run)

本專案採用純原生 Web 技術（Vanilla HTML / CSS / JavaScript），無繁瑣的打包編譯流程：

```bash
# 1. 複製專案庫
git clone https://github.com/SuperBalabah/super_mind_odyssey.git
cd super_mind_odyssey

# 2. 啟動本機靜態伺服器 (任選一種方式)
# 方式 A：使用 Python 3
python -m http.server 8080

# 方式 B：使用 Node.js
npx serve .

# 3. 在瀏覽器打開 http://localhost:8080 即可進行本機體驗與開發
```
